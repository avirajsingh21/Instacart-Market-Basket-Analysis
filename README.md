# Instacart-Market-Basket-Analysis
Market Basket Analysis and Product Recommendation System built using transactional grocery data.

# Business Problem

Customers often purchase related products together, but these relationships are not always utilized effectively for personalized recommendations and cross-selling. This project analyzes purchasing patterns to improve product recommendations and business decisions.
